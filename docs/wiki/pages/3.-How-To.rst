How To
===================================

Requirements
++++++++++++++

* Python 3.11+
* PIP

Clone and Run
++++++++++++++

.. code-block:: bash

   $ git clone https://github.com/zacharytomlinson/saspy.git
   $ cd saspy
   $ python -m pip install -e .
   $ python examples/query_machine.py /dev/ttyUSB0

For the optional application-level YAML configuration example:

.. code-block:: bash

   $ python -m pip install -e '.[examples]'
   $ nano examples/config.yml
   $ python examples/configured_query.py examples/config.yml
